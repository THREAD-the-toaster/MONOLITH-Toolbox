# Privacy policy

The current MONOLITH Toolbox prototype does not implement network communication,
telemetry, analytics, automatic update checks or application downloads. It does not
transfer information to other networked systems.

To obtain icons, it reads application registration data and common installation
paths locally. It reads Windows icon resources and the assets distributed with
MONOLITH. These lookups do not upload file contents or registry data.

Workspace creation writes starter files to the directory explicitly selected by
the user and asks Windows Explorer to open that directory. Workspaces are not
uploaded. If the user selects a network-backed directory, Windows or the user's
storage provider may handle that location according to its own settings.

GitHub builds and any future signing requests are development/distribution services,
not communications initiated by the desktop program. Their providers have their
own privacy policies. This policy must be reviewed before adding network features.
